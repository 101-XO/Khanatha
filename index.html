/ / INTERPOLATED MIL

Elevation is interpolated between measured firing-table rows. An out-of-range elevation is never invented.

/ / VERTICAL OFFSET

Distance is horizontal and does not account for terrain height differences. Corrections may be needed in-game.

/ / AXIS REFERENCE

0° = north, 90° = east, 180° = south, 270° = west. Compass MIL uses 6,400 units per turn.

/ / LOCAL & OFFLINE

The calculator runs locally in your browser. Your coordinates are saved only on this device; no account or API is required.
